# Contributing to DeyeCloud AI Skills

Thanks for your interest! A few guidelines:

## Reporting issues

- Use the issue templates.
- For MCP/API behavior questions, include your `data_center` and the tool name.
- **Never paste your AppSecret or access token.** Create a redacted reproduction.

## Proposing changes

1. Open an issue first to discuss the change (especially for new scenarios).
2. Fork → branch → PR.
3. Keep `SKILL.md` frontmatter in sync: `version` is date-based `vYYMMDD`.
4. Run `node scripts/pack-skills.mjs` to verify the bundle still builds.

## Skill authoring rules

- One `SKILL.md` per skill, with frontmatter `name` / `description` / `version` / `author`.
- `description` is what the AI uses to decide when to load the skill — be specific
  with trigger words (both EN and ZH where relevant).
- Reference tools by their MCP name, not by endpoint path.
- Keep scenarios in the `deye-cloud-scenarios` skill; keep API-level guidance in
  `deye-openapi-quickstart` / `deye-monitoring-best-practices`.

## Releases

Releases are tagged `vYYMMDD` and attach `deye-open-mcp-skills-v<version>.zip`.
The version is generated by `scripts/pack-skills.mjs` and mirrored in
`public/skills/latest-version.txt` on the portal.
